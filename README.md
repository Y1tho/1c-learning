# 1c-learning

Учебная конфигурация 1С:Предприятие 8.3 «Пособие для начинающих».
Репозиторий содержит выгрузку конфигурации в XML-файлы из Конфигуратора.
Создан в процессе изучения платформы 1С по роадмапу разработчика.

## Что это

Исходники конфигурации: объекты метаданных (справочники, документы,
регистры) и модули на встроенном языке BSL. Сама база данных
(файл 1Cv8.1CD) в репозиторий не входит.

## Как открыть

1. Установите учебную версию платформы 1С:Предприятие 8.3
   (бесплатно на online.1c.ru).
2. Создайте пустую файловую информационную базу.
3. Откройте её в Конфигураторе.
4. Меню «Конфигурация» -> «Загрузить конфигурацию из файлов».
5. Укажите папку с выгрузкой из этого репозитория,
   формат: XML-файлы.
6. Обновите конфигурацию базы данных (F7) и запустите
   базу в режиме «1С:Предприятие».

## Как сохранить изменения

Выгрузите конфигурацию в ту же папку: «Конфигурация» ->
«Выгрузить конфигурацию в файлы», затем:

git add .
git commit -m "Что изменил"
git push
